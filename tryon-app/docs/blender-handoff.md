# Передача задачи: 21 модель женщин 50–90 кг в Blender

Отчёт для нового чата в **локальном** Claude, где подключён Blender (MCP).
Предыдущая работа шла в облачной сессии: там нет доступа к Blender пользователя
и закрыт каталог расширений Blender, поэтому задачу лучше доделать локально.

---

## 1. Контекст проекта

- Репозиторий: `aiti0293/Roblox-places`, ветка `claude/relaxed-einstein-8h8tty`.
- Приложение — `tryon-app/`: мини-приложение магазина одежды (Telegram/MAX) для
  женщин 40+. React + Vite + Tailwind + Framer Motion, **без 3D** (от Three.js
  отказались).
- Экран: «ВЫБРАННАЯ ОДЕЖДА», галерея фото со свайпом, кнопка «МАНЕКЕН»
  (фото на модели / на вешалке), карточки «ВЕС кг» (60) и «РОСТ см» (165),
  бейдж «Ваш размер» (`src/lib/size.js`, таблица — `src/config/sizeChart.js`),
  кнопка «Далее».
- Палитра (токены в `src/index.css`): фон `#f8f4ee`, текст `#2e2420`,
  роза `#b26a5e`, шалфей `#62806a`, карамель `#8a5a2e`.
- Пользователь общается **по-русски**; код, переменные и файлы — по-английски.

## 2. Задача

Создать в Blender **21 модель женщины** весом **50, 52, 54 … 90 кг** (шаг 2 кг),
рост **165 см** у всех. Пользователь просил «10 или 20» — 21 модель с шагом 2 кг
покрывает обе крайние точки.

Требования, выясненные раньше в этом проекте:
- **Не собирать тело из примитивов** (сфер, капсул, SDF) — пользователь дважды
  отверг такие варианты как «игрушечные». Нужна реалистичная анатомия.
- **Поза:** руки свободно опущены вдоль тела, почти вертикально, без излома
  в локте и без A-позы. У полных фигур руки чуть отходят от бёдер, но не
  «врастают» в них.
- **Манекен без головы** (как витринный), матовый тёплый материал. Голову со
  слишком реалистичным лицом без текстур кожи лучше не показывать — выглядит
  жутковато.
- Аудитория — женщины 40+: возраст модели ~45–50 лет, а не 25.

## 3. Рекомендуемый путь: MPFB (MakeHuman для Blender)

**MPFB** — официальное расширение MakeHuman для Blender
(Edit → Preferences → Get Extensions → поиск «MPFB»). Оно содержит
реалистичную базовую сетку, макро-параметры (пол, возраст, мышцы, вес, рост,
пропорции) и готовые риги с весами.

**Лицензия:** базовая сетка и таргеты MakeHuman — **CC0** (в архиве таргетов
прямо записано `author: MakeHuman Team, license: CC0, (c) makehumancommunity.org
2001-2020`). Для коммерческого магазина подходит; одежду/кожу из сторонних
наборов MakeHuman проверять отдельно (часть — CC-BY).

### Шаги

1. Через Blender MCP проверить, установлен ли MPFB; если нет — попросить
   пользователя поставить его из Get Extensions (это делается в UI один раз).
2. Изучить API MPFB в установленной версии (модули `services/humanservice.py`,
   `services/targetservice.py` внутри расширения). **Точные имена функций не
   проверены** — сначала посмотреть код, а не угадывать.
3. Для каждого веса создать человека с параметрами:
   - gender = 0.0 (женщина), age ≈ 0.65–0.69 (≈ 45–50 лет: в MakeHuman
     age 0.5 = 25 лет, 1.0 = 90 лет, `years = 25 + (age − 0.5)·130`),
   - muscle = 0.5, proportions = 0.5,
   - ethnic: caucasian ≈ 0.8, african/asian ≈ 0.1 (российская аудитория;
     обсудить с пользователем),
   - **weight и height подобрать калибровкой** (см. п. 4).
4. **Калибровка кг и см** (макро-параметры MakeHuman не в кг):
   - рост — по габаритам меша (в MakeHuman 1 единица = 1 дм; в MPFB обычно уже
     метры — проверить), подобрать `height`, чтобы вышло 165 см;
   - вес — объём меша тела (только материал/группа `body`, без хелперов) ×
     плотность ≈ 1010 кг/м³; бинарным поиском подобрать `weight` под 50…90 кг.
     После изменения веса рост слегка «плывёт» — повторить 2–3 итерации.
   - Для контроля: формула MakeHuman по Мостеллеру
     `kg = BSA² · 3600 / height_cm`, где BSA — площадь поверхности тела в м².
   - Если 90 кг не достигается при weight = 1.0 — сообщить пользователю,
     а не экстраполировать молча.
5. **Поза «руки вниз»:** добавить риг MPFB (default или game_engine), повернуть
   `upperarm01.L/R` вниз (базовая поза MakeHuman — A-поза ~45°). Угол подбирать
   для каждой модели: минимальный, при котором между предплечьем/кистью и
   бедром остаётся ~1–1.5 см. Применить позу (Apply pose as rest или
   применить Armature modifier), проверить подмышки и плечи на заломы.
6. **Без головы:** разрезать по середине шеи (bisect по горизонтальной
   плоскости между суставами `neck01` и `head`), удалить всё выше, закрыть
   отверстие (Fill / Grid Fill). Удалить хелперы (tights, skirt, глаза, зубы,
   язык, кубы суставов), если MPFB их создал.
7. **Материал:** матовый «витринный» — цвет около `#e9ddd0`, roughness ~0.55,
   лёгкий sheen. Subdivision Surface уровень 1 для гладкости.
8. **Экспорт** каждой модели:
   - `tryon-app/public/models/women/woman-165-{kg}kg.glb` (Draco или meshopt,
     без хелперов, с применённой позой), цель — < 500 КБ на файл;
   - один общий `women-50-90.blend` со всеми моделями в ряд (для пользователя;
     в git его не класть, если > ~20 МБ).
9. **Рендеры** (одинаковая камера и свет для всех, чтобы сравнение было честным):
   - фронтальный и 3/4, 1080×1350 (4:5), фон `#f8f4ee`, мягкие area-лампы,
     тень на полу; Cycles + денойз;
   - `tryon-app/public/renders/women/woman-165-{kg}kg-front.webp` (и `-34`);
   - сводный лист `women-contact-sheet.png` со всеми 21 моделями в ряд с
     подписями весов — показать пользователю первым.
10. Записать в `tryon-app/public/models/women/manifest.json` фактические
    параметры: кг (по объёму), рост, обхваты груди/талии/бёдер (срез меша на
    соответствующей высоте) и подобранные макро-значения MPFB. Обхваты
    пригодятся для таблицы размеров (`src/config/sizeChart.js`).

## 4. Запасной путь (если MPFB поставить нельзя)

Все данные MakeHuman доступны из публичных реестров пакетов:
- **Таргеты:** PyPI `makehuman==1.3.2` (wheel), файл
  `makehuman/data/targets.npz`. Вектора — `int16`, умножать на **1e-3**;
  индексы — `uint16`. Ключи вида
  `targets/macrodetails/universal-female-old-averagemuscle-maxweight.{index,vector}.npy`,
  рост — `targets/macrodetails/height/female-…-maxheight`, пропорции —
  `targets/macrodetails/proportions/…`, этнос — `targets/macrodetails/caucasian-female-old`.
  Лицензионная запись в npz — pickle-объект: **не грузить с allow_pickle=True**,
  читать как сырые байты.
- **Базовая сетка + скелет + веса скиннинга:** npm `makehuman-data@0.0.2`,
  файл `public/data/models/human_full_size.json` (three.js JSON 3.1:
  19 158 вершин, лица — квады с типом 11 = quad + material + vertexUV,
  326 «костей» включая псевдокости `*____head`, 4 влияния на вершину,
  `metadata.joint_pos_idxs` — индексы вершин для позиций суставов).
  Материал 0 = `body`, остальные — хелперы. Метка лицензии в этом файле —
  старая (AGPL, 2015); сама сетка hm08 позже вышла под CC0 — уточнить.
- **Формулы смешивания макро-таргетов** (из `apps/human.py`):
  - `femaleVal = 1 − gender`;
  - age ≥ 0.5: `oldVal = 2·age − 1`, `youngVal = 1 − oldVal`;
  - weight/muscle: `max = max(0, 2v − 1)`, `min = max(0, 1 − 2v)`,
    `average = 1 − max − min`;
  - height: `maxheight = max(0, 2h − 1)`, `minheight = max(0, 1 − 2h)`;
  - вес таргета = произведение значений его переменных (например,
    `universal-female-old-averagemuscle-maxweight` =
    femaleVal·oldVal·averagemuscleVal·maxweightVal).
- Blender ставится как модуль: `uv venv -p 3.11 && uv pip install bpy`
  (проверено: bpy 5.0.1 работает в Python 3.11).

## 5. Что спросить у пользователя в начале нового чата

1. Нужна ли голова или делаем безголовый манекен (по умолчанию — без головы).
2. Рост: всем 165 см или ещё серию 155/175.
3. Для чего модели в приложении: рендеры в галерею по кнопке «МАНЕКЕН»
   (подбирать фото по введённому весу) или вернуть 3D-просмотр.
