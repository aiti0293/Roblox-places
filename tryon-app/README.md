# Примерочная — мини-приложение (Telegram / MAX)

```bash
npm install
npm run dev      # http://localhost:5173 (--host: доступно с телефона в той же сети)
npm run build    # статическая сборка в dist/
```

## Экран
```
ВЫБРАННАЯ ОДЕЖДА            [МАНЕКЕН]
┌────────── галерея фото ──────────┐   свайп / стрелки / точки
└──────────────────────────────────┘
[ ВЕС кг  − 60 + ]  [ РОСТ см − 165 + ]   удержание «−/+» — быстро
[Ваш размер: 46 M]           (Далее →)
```

## Структура
| Файл | Назначение |
|---|---|
| `src/App.jsx` | Раскладка экрана |
| `src/data/product.js` | Товар и фото (наборы «на модели» / «на вешалке») — сюда подключаются реальные данные |
| `src/ui/Gallery.jsx` | Галерея: drag 1:1, пружинная докрутка, резинка на краях, стрелки, точки, клавиатура |
| `src/ui/Photo.jsx` | Фото с плавным появлением, «шиммер» при загрузке, аккуратная заглушка при ошибке |
| `src/ui/MannequinToggle.jsx` | Кнопка «МАНЕКЕН» (на модели / на вешалке) |
| `src/ui/ParamCard.jsx`, `useHoldRepeat.js` | Крупные карточки веса и роста, «−/+» с автоповтором |
| `src/ui/NextButton.jsx` | Кнопка «Далее» с тактильной анимацией |
| `src/store/useBodyStore.js` | Вес и рост (Zustand) |
| `src/config/sizeChart.js` | **Таблица размеров** — правьте числа под реальные мерки магазина |
| `src/lib/size.js` | `getRecommendedSize(weight, height)` и `getSizeFit` (размер + «вне таблицы») |
| `src/ui/SizeBadge.jsx` | Бейдж «Ваш размер» |

## Как настроить таблицу размеров
В `src/config/sizeChart.js` для каждой полосы роста задан массив `maxWeight` —
максимальный вес (кг, включительно) для размеров 42, 44, 46, 48, 50, 52.
Пример: рост 160–165 и вес 50–55 → 44. Если вес больше предела для 52-го —
показывается «Ближайший размер: 52».
