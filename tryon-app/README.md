# Примерочная — 3D мини-приложение (Telegram / MAX)

```bash
npm install
npm run dev      # http://localhost:5173 (с --host — доступно с телефона в той же сети)
npm run build    # статическая сборка в dist/
npm run bake     # перезапечь манекен после правок в src/three/procedural/bodySdf.js (~10 с)
```

## Экран (по эскизу)
```
┌ Выбранная одежда ┬ Манекен (3D) ┐
├ лента карточек   ┤    ‹ ○ ›      │
└ Вес, кг ◎          Рост, см ◎   ┘
```
Карточка: нажать — надеть, ещё раз — снять (по одной вещи в слое: верх / жакет / низ).
Манекен вращается свайпом и кнопками ‹ ○ ›. Крутилки — пальцем по кругу или «−/+».

## Структура
| Файл | Назначение |
|---|---|
| `src/lib/body.js` | Рост/вес → обхваты, российский размер, дельты для морфов |
| `src/lib/pose.js` | Угол рук от фигуры (общий для запекания и приложения) |
| `src/data/catalog.js` | Каталог: название, цена, слой, цвет, путь к 3D-модели |
| `src/store/*` | Фигура, надетые вещи, угол поворота (Zustand) |
| `src/config/avatar.js` | `AVATAR_URL` и соответствие параметров → shape keys |
| `src/three/GLBAvatar.jsx` | Манекен + одежда; веса морфов применяются ко всем мешам группы |
| `src/three/Garment.jsx` | Вещь на манекене: ткань, плавное появление |
| `src/three/procedural/*` | Генератор тела и одежды (SDF → сетка → морфы), только для `npm run bake` |
| `src/ui/*` | Панель выбранной вещи, лента карточек, крутилки, кнопки поворота |

## Морф-таргеты
`Bust_Plus/Minus`, `Waist_Plus/Minus`, `Hips_Plus/Minus` — ±30 см обхвата от базы
(рост 166, грудь 94, талия 76, бёдра 102); `Arms_Out` — отведение рук на 0,25 рад.
У вещей те же морфы, поэтому они садятся на любую фигуру.

## Требования к своей GLB
- Безголовый манекен, метры, стоит на Y=0, смотрит в +Z.
- Те же shape keys (имена меняются в `src/config/avatar.js`); `Arms_Out` — по желанию.
- Одежда: тот же скелет/топология и те же shape keys; путь — в `src/data/catalog.js`.
